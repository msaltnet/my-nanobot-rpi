# my-nanobot-rpi 30초 홍보 영상 시나리오 보드

## 방향

앱 광고처럼 기능을 나열하지 않는다.  
핵심 감정은 "내가 직접 만든 나만의 인공지능 비서가 작은 서버 안에서 조용히 살아 있다"이다.

- 톤: 차분한 아침/밤 루틴, 홈서버 감성, 실제 UI 중심
- 화면: 실제 Telegram 대화처럼 보이는 재현 UI + Raspberry Pi/터미널 상태 화면
- 길이: 30초
- 목표: GitHub 방문, 설치 문서 확인, 프로젝트에 대한 호기심 유도

## 핵심 문장

> 내 작은 서버에 비서를 하나 만들었다.

## 30초 구성

| 시간 | 장면 | 화면 | 메시지 |
|---:|---|---|---|
| 0-3초 | 쌓이는 일상 | 어두운 책상 위 휴대폰. 뉴스 알림, 메모, 기록해야 할 루틴이 겹쳐 보인다. | 매일 챙겨야 할 것들이 너무 많아서 |
| 3-6초 | 작은 서버 등장 | 책상 위 Raspberry Pi. 작은 상태등이 켜지고 Telegram 봇 상태가 online으로 바뀐다. | 내 작은 서버에 비서를 하나 만들었다 |
| 6-12초 | 경제 브리핑 | Telegram 대화 화면. "오늘 아침 경제 브리핑"이 도착하고 국내/해외/정책 흐름이 요약된다. | 아침과 저녁, 경제 뉴스는 핵심만 정리하고 |
| 12-18초 | 자연어 기록 | 사용자가 "어제 11시에 잤어", "영어 30분 했어"라고 입력한다. 봇이 기록 완료 메시지를 보낸다. | 생활 기록은 앱을 열지 않고 말하듯 남긴다 |
| 18-23초 | 능동 비서 | 봇이 "오늘 수면 기록이 비어 있어요"처럼 조용히 묻는다. 사용자가 짧게 답한다. | 잊기 전에 묻고, 놓친 건 다시 챙긴다 |
| 23-27초 | 내 서버에서 운영 | 터미널 또는 doctor 화면. RSS ok, Telegram ok, SQLite ok, systemd active가 차례로 뜬다. | 클라우드 어딘가가 아니라, 내 서버에서 |
| 27-30초 | 엔딩 | Telegram 화면 위에 프로젝트 이름과 GitHub URL. Raspberry Pi 상태등이 은은하게 깜빡인다. | my-nanobot-rpi. 나만의 인공지능 비서. |

- 영어 공부 기록 없음
- 메모할 것 3개

내레이션/자막:

> 매일 챙겨야 할 것들이 너무 많아서

## 제작 메모

- 실제 개인정보가 들어간 Telegram 스크린샷은 쓰지 않는다.
- Telegram UI는 실제처럼 재현하되, 메시지는 위 초안으로 구성한다.
- 기존 영상의 추상 카드 UI보다 휴대폰 대화 화면을 중심에 둔다.
- Raspberry Pi 장면은 사진/생성 이미지/간단한 실사풍 연출 중 하나를 선택한다.
- 음악은 과장된 테크 광고보다 낮고 차분한 전자음 계열이 어울린다.
- 효과음은 Telegram 메시지 도착, 키 입력, 작은 서버 상태등 정도만 절제해서 쓴다.
