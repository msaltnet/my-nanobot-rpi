# YouTube 마케팅 캠페인 문서: my-nanobot-rpi Intro

## 1. 캠페인 개요

### 캠페인명

`my-nanobot-rpi`: 라즈베리파이 위의 개인 AI 비서

### 대상 영상

- 파일: `remotion-project/out/nanobot-intro.mp4`
- 길이: 60초
- 비율/해상도: 16:9, 1920x1080
- 핵심 메시지:
  - 라즈베리파이에서 조용히 돌아가는 개인 AI 비서
  - RSS 11개 경제 뉴스 소스를 GPT로 요약해 아침/저녁 텔레그램 브리핑 제공
  - 수면, 음주, 영어 공부, 메모 등 생활 기록을 자연어로 데이터화
  - systemd, cron, doctor 점검으로 장기 운영 가능한 개인 서버 프로젝트

### 캠페인 목적

초기 목적은 직접 판매보다 관심 있는 개발자/메이커에게 프로젝트를 발견시키고, GitHub 방문과 설치 시도를 늘리는 것이다.

우선순위:

1. GitHub 저장소 방문
2. README/설치 문서 조회
3. GitHub star, fork, clone
4. 실제 라즈베리파이 또는 홈서버 설치
5. 이후 블로그/뉴스레터/커뮤니티 유입 기반으로 리마케팅

## 2. 포지셔닝

### 한 줄 정의

라즈베리파이에 설치해 경제 뉴스와 생활 기록을 텔레그램으로 챙겨주는 오픈소스 개인 AI 비서.

### 핵심 가치 제안

- 매일 보는 경제 뉴스 흐름을 자동으로 압축한다.
- 생활 기록을 앱 입력 폼이 아니라 자연어 대화로 남긴다.
- 클라우드 서비스 구독형 비서가 아니라 내 작은 서버에서 직접 운영한다.
- 개발자와 메이커가 이해하고 고칠 수 있는 Python 기반 프로젝트다.

### 톤

과장된 생산성 도구보다는 “조용히 계속 챙겨주는 개인 서버”에 가깝게 말한다.  
광고 문구는 기술적 신뢰와 생활 밀착감을 같이 가져간다.

## 3. 타깃 오디언스

### 1차 타깃

개발자, 라즈베리파이 사용자, 홈서버/셀프호스팅 관심층

- 관심사: Raspberry Pi, Python, Telegram bot, OpenAI API, automation, self-hosted, homelab
- 행동: GitHub 방문, 오픈소스 튜토리얼 시청, 개발자 도구 리뷰 시청
- 메시지: “작은 서버 하나로 개인 루틴을 자동화하세요.”

### 2차 타깃

AI 자동화와 개인 생산성에 관심 있는 지식근로자

- 관심사: AI assistant, GPT, productivity, personal knowledge management, quantified self
- 행동: 생산성 앱 비교, AI 워크플로 영상 시청
- 메시지: “뉴스와 생활 기록을 텔레그램 대화로 가볍게 관리하세요.”

### 3차 타깃

경제 뉴스와 시장 흐름을 꾸준히 챙기고 싶은 개인 투자자

- 관심사: 경제 뉴스, 금리, Fed, 금융시장 브리핑, 투자 루틴
- 행동: 경제 유튜브, 뉴스 요약 콘텐츠 소비
- 메시지: “아침과 저녁, 중요한 경제 흐름만 압축해서 받으세요.”

## 4. 캠페인 구조

### Phase 1. 검증 캠페인

기간: 14일

목표:

- 어떤 타깃이 영상을 끝까지 보는지 확인
- GitHub/문서 클릭 가능성이 있는 메시지 찾기
- 60초 영상이 광고 소재로 충분한지, 15초/6초 컷다운이 필요한지 판단

권장 구조:

| 캠페인 | 목적 | 소재 | 예산 비중 | 성공 기준 |
| --- | --- | --- | --- | --- |
| Video views | 관심 검증 | 60초 원본 | 40% | 조회율, 25/50/75/100% 시청률 |
| In-feed video | 탐색 유입 | 60초 원본 + 썸네일 | 30% | 클릭률, GitHub 방문 |
| Skippable in-stream | 메시지 테스트 | 60초 원본 | 20% | 5초 이후 유지율, CTA 클릭 |
| Shorts 테스트 | 모바일 발견 | 15초 세로 컷 필요 | 10% | Shorts view, CTA 반응 |

Google Ads 기준으로 YouTube 광고 형식은 skippable in-stream, non-skippable in-stream, in-feed, bumper, Shorts 등을 사용할 수 있다. 현재 60초 원본은 in-feed와 skippable in-stream에 먼저 적합하고, bumper/Shorts는 별도 컷다운 제작이 필요하다.

### Phase 2. 확장 캠페인

기간: Phase 1 이후 30일

목표:

- 성과가 좋은 타깃/카피 조합에 예산 집중
- 15초 버전과 6초 버전 제작
- GitHub 방문자, 영상 시청자 기반 리마케팅 구성

확장 조건:

## 10. 측정 지표

### YouTube/Google Ads 지표

- 조회수
- TrueView views
- CPV
- 조회율
- 25%, 50%, 75%, 100% 시청률
- 클릭률
- CTA 클릭
- 전환당 비용

CPV 과금은 광고 형식에 따라 다르다. 예를 들어 in-stream은 30초 시청, 영상이 30초보다 짧으면 전체 시청, 또는 상호작용 중 먼저 발생한 기준으로 view가 계산된다. Shorts는 10초 시청 또는 CTA 클릭 등이 view 기준에 포함된다.

### 제품/프로젝트 지표

- GitHub 방문 수
- README 클릭/체류
- star 증가
- fork 증가
- clone 또는 release 다운로드
- issue/discussion 생성
- 설치 가이드 조회

## 11. UTM 규칙

### 기본 URL 예시

```text
https://github.com/msaltnet/my-nanobot-rpi?utm_source=youtube&utm_medium=paid_video&utm_campaign=nanobot_intro_2026q2&utm_content=60s_infeed_dev
```

### `utm_content` 규칙

```text
{length}_{format}_{audience}_{message}
```

예시:

- `60s_infeed_dev_overview`
- `60s_instream_homelab_overview`
- `15s_shorts_productivity_tracking`
- `15s_instream_investor_news`
